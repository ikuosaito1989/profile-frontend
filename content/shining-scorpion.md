#### 概要

「チビ四駆 セイラン」は、街やショップを探索し、マシンを組み立ててレースに挑むブラウザゲームです。TypeScript と React で画面を構成し、Phaser による 2D 探索と Three.js による 3D レースを組み合わせています。ゲームの進行やセーブデータはブラウザ内で管理します。

#### 使用技術

- TypeScript / React
- Phaser（2D探索）
- Three.js / WebGL（3Dレース）
- Zustand（状態管理）
- IndexedDB（セーブ）
- Cloudflare Workers Static Assets
